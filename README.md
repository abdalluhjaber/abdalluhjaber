## 🧑‍🎓 نبذة عني

- 🎓 **خريج ممتاز** – بكالوريوس نظم معلومات، جامعة صنعاء (معدل 96.01%).
- 💼 **خبرات عملية حقيقية**:
  - مشروع تخرج حكومي (الكهرباء): تحكم ومراقبة الشبكات بالذكاء الاصطناعي.
  - تدريب في شركة ثروات وRTS: تطوير Full-Stack وتطبيقات موبايل.
- 🧠 **باني نماذج تعلم آلي** – تنبؤ بالسكتة الدماغية، تحليل بيانات، XGBoost.
- 📱 **مطور متعدد المنصات** – Flutter للموبايل، React/Next.js وASP.NET للويب.
- 🌐 **لدي موقع شخصي يعرض أعمالي** – [my-cv-platform.netlify.app](https://my-cv-platform.netlify.app).
