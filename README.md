## 🧑‍🎓 عني بصورة سريعة

- 🎓 **خريج جامعة صنعاء – كلية الحاسوب وتكنولوجيا المعلومات** (نظم معلومات) بتقدير **ممتاز (96.01%)**، دفعة 2022-2026.
- 💼 **خبرة عملية** في مشاريع حكومية (الكهرباء) وشركات تقنية (ثروات بالتعاون مع RTS).
- 🧠 **مهتم بالذكاء الاصطناعي** وتعلم الآلة – نفذت نموذج تنبؤ بالسكتة الدماغية باستخدام Gradient Boosting.
- 📱 **أطور تطبيقات الموبايل** باستخدام Flutter/Dart، وكذلك الواجهات الخلفية بـ ASP.NET Core وLaravel وPython.
- ⚡ **حاصل على دبلوم لغة إنجليزية (مستوى 3B)** من معهد Foreo American Institute.
- 🌐 **أمتلك موقعاً شخصياً** لعرض أعمالي: [my-cv-platform.netlify.app](https://my-cv-platform.netlify.app)
